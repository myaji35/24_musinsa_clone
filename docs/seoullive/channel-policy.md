# SeoulLive 검증 단계 외부 송출 정책 (ISS-182)

- 작성: 2026-11-10 공장 실행(factory-runner). 공식 페이지 확인일 2026-11-10
- 대상: 사전 제작한 AI 클립(AI 쇼호스트·AI 모델)을 15분 사이클로 편성해 장시간 라이브로 송출하고, 화면 QR·설명란 링크로 JIEUM 몰·쇼피파이로 보내는 검증 방송(ISS-176 A)
- 표기: **[공식]** 공식 페이지 본문에서 직접 확인 / **[색인 발췌]** 공식 페이지지만 본문을 열지 못해 검색 색인 문구만 확인(운영 전 재확인 필요) / **[확인 못함]** 공식 출처를 찾지 못함(추측하지 않음)

## 결론
1. **검증 단계 송출 채널 1순위: 유튜브 라이브(PC 인코더 송출).** 사전 녹화 송출을 직접 금지하는 공식 조항을 찾지 못했고, 전화번호 인증만으로 PC 라이브가 열리며 구독자 기준이 없다. 설명란 클릭 링크와 화면 QR을 쓸 수 있다. 다만 수익화(YPP)는 "inauthentic content" 조항 때문에 기대하지 않고, 검증 목표를 **링크별 유입·판매 측정**에 둔다.
2. **2순위: 틱톡은 LIVE가 아니라 일반 영상(쇼츠형) 업로드 + AI 라벨.** 틱톡은 녹화 콘텐츠 LIVE 송출을 공식적으로 "권장하지 않음"이라 하고, 무인·반복 LIVE는 수익화에서 빠지거나 노출이 줄 수 있다. 한국은 TikTok Shop 운영 국가가 아니고, PC 송출 키(LIVE Producer) 발급 조건도 공식 확인이 안 된다.
3. 두 플랫폼 모두 **사실적인 AI 인물 콘텐츠는 AI 표시가 의무**다. 방송 화면에도 "AI 쇼호스트 / AI Host", "AI 모델 / AI Model", "사전 제작 영상" 표시를 고정한다(ISS-184 라벨 규칙, ISS-179 법무와 연결).

## 1. 유튜브

### 1-1. 사전 녹화 영상을 라이브로 송출, 반복 24시간 라이브
- "사전 녹화 영상을 라이브로 내보내도 된다/안 된다"는 명시 조항 — **[확인 못함]** 스팸 정책·라이브 제한 회피 페이지 모두 다루지 않음. ([스팸·기만 정책](https://support.google.com/youtube/answer/2801973?hl=en), [라이브 제한 회피](https://support.google.com/youtube/answer/2853834?hl=en))
- 라이브의 모든 콘텐츠는 커뮤니티 가이드와 서비스 약관을 따른다. **[공식]** ([라이브 시작](https://support.google.com/youtube/answer/9228390?hl=en))
- 이 방송과 관련된 스팸·기만 금지 조항 **[공식]** ([출처](https://support.google.com/youtube/answer/2801973?hl=en))
  - 외부 사이트로 보내는 것만이 목적인 콘텐츠
  - 참여를 인위적으로 부풀리려는 반복·템플릿 콘텐츠
  - 악의적으로 오도하는 제목·썸네일·설명
  - 대량·반복·기만적인 댓글과 라이브 채팅
- 수익화(YPP) 정책: 2025-07-15 "repetitious content"가 "inauthentic content"로 바뀌었고, 대량 생산 인상을 주는 템플릿형 AI 콘텐츠, 변화가 거의 없는 반복 콘텐츠, 같은 캐릭터가 같은 상황·결과를 반복하는 영상은 수익화 불가 예시다. **게시 금지가 아니라 수익화 자격 조항이다.** **[공식]** ([출처](https://support.google.com/youtube/answer/1311392?hl=en))

### 1-2. AI 생성·변경 콘텐츠 표시('변경되거나 합성된 콘텐츠')
- 표시해야 하는 경우: 사실처럼 보이는 AI 생성·변경 콘텐츠 — 실제 인물이 하지 않은 말·행동, 실제 장소·사건 변경, 일어나지 않은 현실적 장면. **[공식]** ([출처](https://support.google.com/youtube/answer/14328491?hl=en))
- 표시하지 않아도 되는 경우: 비현실적 콘텐츠(애니메이션 등), 미용 필터·색 보정·자막 같은 사소한 편집. **[공식]** (같은 출처)
- **JIEUM 방송은 사실적인 AI 인물이 옷을 소개하므로 표시 대상이다.**
- 설정 위치(업로드 영상): YouTube Studio 업로드 화면 → 속성(Attributes) → **"AI use"**(예전 이름 "Altered content")에서 '예'. **[공식]** ([출처](https://support.google.com/youtube/answer/14328491?hl=en), [업로드 도움말](https://support.google.com/youtube/answer/57404?hl=en&co=GENIE.Platform%3DDesktop))
- 설정 위치(라이브 스트림) — **[확인 못함]** 표시 의무·라이브 설정 페이지 모두 라이브용 표시 방법을 적지 않음. ([라이브 설정](https://support.google.com/youtube/answer/9854503?hl=en)) → 라이브 설정 화면에서 같은 항목이 있으면 '예'로 두고, 없더라도 **화면 자막으로 상시 표시**한다.
- 표시하지 않을 때 불이익: 유튜브가 라벨을 직접 붙일 수 있고, 계속 누락하면 콘텐츠 삭제·YPP 정지 등 제재. **[공식]** ([출처](https://support.google.com/youtube/answer/14328491?hl=en))

### 1-3. 라이브 자격, 상품 판매·외부 링크
- 라이브 자격: 16세 이상, 채널 인증, 최근 90일 라이브 제한 없음. 채널당 동시 활성 스트림 10개, 스트림 키당 3개. 경고(strike) 1회 시 14일 라이브 불가. **[공식]** ([출처](https://support.google.com/youtube/answer/2474026?hl=en))
- PC(인코더) 라이브는 '중급 기능' — 전화번호 인증으로 열림(Studio > 설정 > 채널 > 기능 사용 자격). **[공식]** ([출처](https://support.google.com/youtube/answer/9890437?hl=en), [출처](https://support.google.com/youtube/answer/9891124?hl=en))
- 모바일 라이브는 구독자 50명 이상. 첫 라이브 전 24시간 대기가 있을 수 있음. **[공식]** ([출처](https://support.google.com/youtube/answer/9228390?hl=en))
- 라이브 제한 상태에서 다른 채널로 라이브하면 위반. **[공식]** ([출처](https://support.google.com/youtube/answer/2853834?hl=en))
- **설명란 클릭 링크는 '고급 기능'** — 전화번호 인증 + 채널 이력 또는 신분증·영상 인증 필요. **[공식]** ([출처](https://support.google.com/youtube/answer/9890437?hl=en))
- 외부 링크 정책은 라이브에도 적용되고, **화면에 보이는 URL 텍스트도 링크로 본다.** 위반 URL이 영상·메타데이터에 있으면 삭제될 수 있다. 제휴 콘텐츠 자체는 허용되나 전용 계정으로 과도하게 올리면 스팸 위반 소지. **[공식]** ([출처](https://support.google.com/youtube/answer/9054257?hl=en))
- 유튜브 쇼핑(자사 스토어 연결): YPP 가입·구독자 기준 필요. 페이지에 한국은 '다른 브랜드 상품 홍보(제휴)' 자격 국가로만 나오고, 자사 스토어 자격 국가 목록에서는 한국을 확인하지 못함. Cafe24가 연동 플랫폼으로 언급됨. **[공식]** ([출처](https://support.google.com/youtube/answer/12257682?hl=en)) → 검증 단계에서는 유튜브 쇼핑 대신 **QR·설명란 링크 + ISS-070 유입 추적**으로 측정한다.
- 라이브 채팅 링크 차단 설정 세부 — **[확인 못함]**

### 1-4. 장시간 송출 운영상 주의
- 12시간 미만 스트림은 자동 보관, **12시간을 넘으면 보관이 아예 안 될 수 있음**("may not be captured at all"). 로컬 백업 녹화 권장. **[공식]** ([출처](https://support.google.com/youtube/answer/6247592?hl=en), [출처](https://support.google.com/youtube/answer/9228389?hl=en))
- 인코더 자동 시작·자동 중지, DVR 설정이 있음. **[공식]** ([출처](https://support.google.com/youtube/answer/9854503?hl=en))
- 12시간 초과 시 강제 종료 여부, 연속 송출 상한 — **[확인 못함]** → 편성은 **12시간 미만 단위로 끊어 재시작**(ISS-186 편성기 요구사항으로 넘김).

## 2. 틱톡

### 2-1. LIVE 자격과 PC/OBS 송출 키
- LIVE는 18세 이상. **[공식]** ([커뮤니티 가이드 — 계정·기능](https://www.tiktok.com/community-guidelines/en/accounts-features))
- 팔로워 1,000명(지역마다 다를 수 있음), 한국에서 선물 주고받기는 19세 이상. **[색인 발췌]** ([출처](https://www.tiktok.com/support/faq_detail?id=7543604790438451768&category=web_account))
- TikTok LIVE Studio 접근 조건: 계정 생성 후 일정 일수, 최근 일정 시간 이상 LIVE, 일정 팔로워 수, 최근 정지 이력 없음 — 구체 수치는 "국가·지역별로 다르고 예고 없이 바뀔 수 있다"고만 적혀 있음. 다른 플랫폼 방송 채널 정보로 신청 가능, 심사 며칠. **[공식]** ([출처](https://www.tiktok.com/live/studio/help/article/Before-you-go-LIVE/Apply-for-LIVE-access?lang=en))
- LIVE Producer(RTMP 스트림 키) 발급 조건 — **[확인 못함]** ("에이전시를 통해서만 발급"이라는 말은 비공식 출처라 쓰지 않음)
- **JIEUM 틱톡 계정이 위 조건(나이·팔로워 수·LIVE 이력·정지 이력)을 충족하는지: 대표님 확인 필요.** 계정 소유자만 앱의 LIVE 메뉴·LIVE Studio 신청 화면에서 확인할 수 있다.

### 2-2. 사전 녹화 송출·무인 방송
- 커뮤니티 가이드 LIVE 조항에 사전 녹화 송출을 명시적으로 금지하는 문장은 없음. 타인 콘텐츠 무단 송출은 제한 사유, 위반 시 세션 중단·일시 LIVE 제한, 반복 시 계정 정지. 상업 콘텐츠는 상업 공개 토글로 밝혀야 함. TikTok Shop 시장에서는 플랫폼 밖 구매를 유도하는 LIVE의 노출을 줄임. **[공식]** ([출처](https://www.tiktok.com/community-guidelines/en/accounts-features))
- LIVE Studio 도움말: "녹화 콘텐츠를 TikTok LIVE로 송출하는 것은 권장하지 않음", 크리에이터가 방송 내내 화면에 있기를 권장, 오래 자리를 비우면 참여 부족으로 볼 수 있음, 상호작용이 적으면 녹화 콘텐츠로 인식될 가능성이 커짐. **[공식]** ([출처](https://www.tiktok.com/live/studio/help/article/Before-you-go-LIVE/Community-Guidelines?lang=en))
- LIVE 수익화 가이드라인: 실제 라이브처럼 보이는 사전 녹화·반복 재생 영상, 수동적·반복적·무인 콘텐츠는 수익화 대상이 아닐 수 있음, 반복 위반 시 영구 제한 가능. **[색인 발췌]** ([출처](https://www.tiktok.com/live/creators/en-US/rules_and_guidance/live_monetization_guidelines))
- TikTok Shop 셀러 교육(미국): "LIVE 중에는 특히 사전 녹화 영상·음성을 피하라". **[공식]** ([출처](https://seller-us.tiktok.com/university/essay?knowledge_id=565946717964075))

### 2-3. AI 생성 콘텐츠(AIGC) 라벨
- 사실적인 장면·인물을 보여 주는 AI 생성 또는 크게 편집된 콘텐츠는 **크리에이터가 라벨을 붙여야 함.** 미표시 시 삭제·제한 또는 틱톡이 라벨 부착. **[공식]** ([출처](https://www.tiktok.com/community-guidelines/en/integrity-authenticity))
- 틱톡 AI 효과로 만든 콘텐츠는 자동 라벨, C2PA 콘텐츠 자격증명도 읽어 라벨 부착. **[공식]** ([출처](https://newsroom.tiktok.com/en-us/new-labels-for-disclosing-ai-generated-content))
- LIVE에 AIGC 라벨을 붙이는 방법·위치 — **[확인 못함]** ([도움말](https://support.tiktok.com/en/using-tiktok/creating-videos/ai-generated-content), 본문 열람 불가)

### 2-4. 한국 TikTok Shop·LIVE 쇼핑
- TikTok Shop 운영 국가(2025-11 갱신): 인도네시아, 아일랜드, 말레이시아, 멕시코, 필리핀, 싱가포르, 스페인, 태국, 영국, 미국, 베트남 — **한국 없음.** **[공식]** ([출처](https://ads.tiktok.com/help/article/considerations-when-launching-your-tiktok-shop-journey))

## 3. 금지·주의 체크리스트 (검증 방송 운영 규칙)
1. 사실적인 AI 인물이므로 유튜브 "AI use"를 '예'로 두고(라이브 설정 위치 미확인 → 화면 자막으로도 상시 표시), 틱톡 업로드에는 AIGC 라벨을 붙인다.
2. 제목·썸네일·설명에 "실시간 진행", "지금 방송 중인 진행자" 같은 오도 표현을 쓰지 않는다. 화면에 "AI 진행자 · 사전 제작 영상"을 적는다.
3. 15분 고정 반복 대신 회차마다 클립 순서·상품·멘트를 바꿔 '변화가 거의 없는 반복'으로 보이지 않게 한다(정책 문구에서 끌어낸 권고, ISS-186 편성기 요구사항).
4. 외부 유도만 하는 방송이 되지 않게 상품 설명·사이즈·코디 정보 같은 방송 자체의 가치를 넣는다(정책 문구에서 끌어낸 권고).
5. 12시간 미만 단위로 방송을 끊어 다시 시작하고, 로컬 녹화를 따로 남긴다.
6. 링크 대상(JIEUM 몰·쇼피파이)이 규제·악성 사이트로 분류되지 않는지 점검하고, **단축 URL은 쓰지 않는다**(화면 URL 텍스트도 링크로 판정됨) — ISS-187 단축 링크 설계 시 원 도메인 + 링크 코드(lc) 파라미터 방식 권장.
7. 채팅창에 같은 링크를 반복해서 올리는 자동 도배를 하지 않는다(ISS-189·190 댓글 자동화 규칙).
8. 경고 1회면 14일 라이브 불가 — 제한 중 다른 채널로 우회 송출하지 않는다.
9. 음원·이미지 저작권을 확인한다(저작권 경고도 라이브 제한 사유).
10. 틱톡에 상업 콘텐츠를 올릴 때는 상업 공개 토글을 켠다.

## 4. 대표님 확인 필요
- 유튜브 채널(JIEUM)의 **전화번호 인증(중급 기능)**과 **설명란 클릭 링크용 고급 기능 인증** 여부 — 송출 연결 카드 ISS-206 전에 필요.
- 틱톡 계정의 LIVE 자격(나이·팔로워 수·LIVE Studio 신청 가능 여부) — 2순위 채널이라 검증 단계에서는 필수 아님.
