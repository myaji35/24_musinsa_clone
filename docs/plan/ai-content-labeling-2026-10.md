# AI 생성 콘텐츠 표시 규정 조사 — JIEUN 가상 인플루언서(강유나) 숏폼

- 작성일: 2026-10-18 (모든 출처 확인일 = 2026-10-18, 별도 표기 없으면)
- 범위: YouTube Shorts · Instagram/Facebook(Meta) · TikTok · 공정위 추천·보증 심사지침 · AI 기본법
- 근거 표기: **[원문]** = 플랫폼 공식 정책·고객센터·법제처·공정위 원문을 직접 열어 확인함. **[공식 블로그]** = 플랫폼 공식 블로그·뉴스룸. **[기사 근거]** = 언론·제3자 블로그만 있음. **확인 불가** = 원문을 찾지 못했거나 열지 못함.
- 이 문서는 법률 자문이 아니다. 과징금·과태료가 걸린 판단(§3)은 출시 전에 변호사 확인을 받는다.

## 0. 업로드 전 체크리스트 1장 (대표님용)

> 강유나가 나오는 영상·사진은 **"모든 플랫폼에서, 매번, 켜고·쓰고·박는다"** 가 원칙이다. 아래 칸을 다 채우기 전에는 올리지 않는다.

### 공통 (어느 플랫폼이든 먼저)
- [ ] **영상 안에 글자 박기**: 강유나가 화면에 나오는 **처음부터 끝까지** 강유나 얼굴·몸 가까이에 `가상 인물` 표시 (배경과 구분되는 색, 작지 않게). → 공정위 지침 필수 사항
- [ ] **사진(썸네일·카드뉴스)에도** 강유나 옆에 `가상 인물` 표시
- [ ] **캡션 첫 줄**에 `[가상 인물 포함] AI로 만든 가상 인물이 등장하는 JIEUN 광고입니다.` (더보기 눌러야 보이는 위치 금지)
- [ ] **"제가 입어봤는데~", "직접 써보니~" 같은 경험담 대사·자막 금지.** 가상 인물은 실제로 입어 본 경험이 없으므로, 표시를 해도 부당광고가 될 수 있다. → "이 옷은 ○○ 소재예요", "이렇게 코디할 수 있어요" 처럼 **상품 사실 설명**으로 바꾼다
- [ ] 실존 인물(연예인·일반인) 얼굴·목소리를 닮게 만들지 않았는지 확인
- [ ] 생성 도구가 C2PA(콘텐츠 자격증명) 메타데이터를 붙였다면 **지우지 않는다** (플랫폼이 자동으로 AI 라벨을 붙여 준다 — 오히려 안전)
- [ ] 외부 인플루언서에게 돈·상품을 주고 올리게 했다면 `광고`/`협찬` 표시도 따로 한다 (가상 인물 표시와 별개)

### YouTube Shorts
- [ ] YouTube 스튜디오(PC 또는 모바일 앱) 업로드 단계 → **'속성' → 'AI 사용' → "예"** 선택
- [ ] (해당 시) 유료 프로모션 체크 — 아래 '확인 못 한 항목' 참고
- [ ] 제목 또는 설명 첫 줄에 `[가상 인물 포함]`

### Instagram (Reels·피드)
- [ ] **프로필 수정 → "AI로 생성한 프로필" 켜기** (강유나 계정에서 1회. 안 켜면 추천·탐색 노출이 제한됨)
- [ ] 게시 화면에서 **"AI 레이블 추가"(AI info) 켜기** — Reels 같은 사실적 영상은 의무
- [ ] 캡션 첫 줄 `[가상 인물 포함]` (해시태그 #가상인물 #AI모델 추가 권장)
- [ ] 외부 크리에이터와 협업 게시면 '유료 파트너십' 레이블

### TikTok
- [ ] 게시 화면에서 **'AI 생성 콘텐츠'(AIGC) 라벨 켜기** (앱의 '더 보기 옵션' 쪽 — 정확한 메뉴명은 앱에서 확인)
- [ ] **'콘텐츠 공개(Content disclosure) 설정' 켜기 → '내 브랜드'** — 자사 상품 홍보는 의무
- [ ] TikTok 광고(Ads Manager)로 돌릴 때: 광고 만들기 화면에서 **"This ad contains AI-generated content" 체크**
- [ ] 캡션 첫 줄 `[가상 인물 포함]`

### 자사몰(상품상세)
- [ ] 강유나 착용 이미지 옆·아래에 `가상 인물` 표기, 상세 상단에 안내 문구 (§5 문구 예시)
- [ ] 실측 사이즈·소재는 **실제 상품 기준**으로 따로 표기 (AI 착용컷의 핏이 실제와 다를 수 있음)

### JIEUN 적용 여부 판단
- **적용 가능성 높음.** 지침의 '추천·보증 등'은 "광고주의 의견이 아닌 **제3자의 독자적인 의견으로 인식될 수 있는**" 사용경험·구매권장 표현이다(Ⅲ.1). 강유나를 **독립 인플루언서처럼** 운영하며("요즘 제가 꽂힌 옷", "추천템") 자사몰로 유도하면 전형적인 추천·보증이다.
- 강유나가 대사 없이 옷만 입는 **순수 모델컷**이면 '추천·보증'이 아닐 여지가 있다. 하지만 SNS 인플루언서 형식이면 경계가 흐려진다. 또 공정위는 '실제와 구분하기 어려운' 가상인물을 대상으로 한다. 그래서 **모든 강유나 콘텐츠에 표시하는 쪽으로 통일**한다(판단).
- 강유나는 JIEUN이 만든 인물이므로 JIEUN이 **광고주이자 추천·보증인 운영자**다. "JIEUN이 만든 가상 인물"임을 밝히면 경제적 이해관계 표시(Ⅴ.6)도 함께 해결된다(판단).
- **Ⅴ.5.다가 가장 큰 위험이다.** "입어보니 안 늘어나요", "세탁해도 멀쩡" 같은 체험형 문장은 가상인물에게 실제 경험이 없으므로 표시를 해도 부당광고가 될 수 있다. 이런 내용은 실측·시험 데이터를 근거로 한 상품 정보 문장으로 바꾼다.

### 불확실한 점
- 공정위가 실제로 점검·제재한 가상인물 사례(심결)는 찾지 못했다 → **확인 불가**.
- '순수 모델 착용컷'이 추천·보증에 해당하는지에 대한 공정위 공식 해석은 없다 → **확인 불가** (그래서 보수적으로 표시 권고).
- 부칙의 경과규정 문구가 어느 개정 차수 것인지 법제처 화면 표기상 불명확. 2026-06-01 이후 게시물에는 어차피 적용되므로 실무 영향은 없다.

## 5. 우리 쪽 권고

### 5-1. 원칙
1. **강유나는 '정체성 자체가 AI'로 운영한다.** 프로필명·소개에 "JIEUN이 만든 AI 가상 모델"을 넣는다. 그러면 Instagram 'AI로 생성한 프로필' 요건, 공정위 지침, 경제적 이해관계 공개를 한 번에 충족한다.
2. **표시는 '플랫폼 토글 + 영상 내 글자 + 캡션 첫 줄' 세 겹으로 한다.** 플랫폼 토글만으로는 공정위 지침(등장하는 동안·근접 위치)을 채우지 못한다.
3. **체험담은 쓰지 않고, 상품 사실만 말한다.** (공정위 Ⅴ.5.다)
4. **C2PA 메타데이터는 남겨 둔다.** 생성 툴이 붙인 자격증명을 지우는 편집·재인코딩은 피한다. 세 플랫폼 모두 이를 읽어 자동 라벨을 붙이므로, 지우면 '숨기려 했다'는 인상만 남는다.
5. **실존 인물과 닮게 만들지 않는다.** TikTok·Meta 모두 실존인 초상·허위 지지를 금지·제재한다.

### 5-2. 표기 문구 예시 (복붙용)

| 위치 | 문구 |
|---|---|
| 영상 화면(강유나 등장 내내, 인물 옆) | `가상 인물` 또는 `AI 가상 인물` (흰 바탕 검정 글자 등 배경과 대비되는 색, 화면 높이의 3~4% 이상 권장 — 크기 수치는 내부 권고이며 법정 기준 아님) |
| 사진·썸네일(인물 옆) | `[가상 인물]` |
| 캡션·설명 첫 줄 | `[가상 인물 포함] AI로 만든 가상 인물 '강유나'가 등장하는 JIEUN 광고입니다.` |
| 블로그·게시글 제목 앞 | `[가상 인물 포함] 강유나의 가을 니트 코디` |
| 프로필 소개 | `JIEUN이 만든 AI 가상 모델 강유나 · 실존 인물이 아닙니다 · #광고` |
| 자사몰 상품상세 상단 | `이 상품의 착용 이미지는 AI로 만든 가상 인물(강유나)입니다. 실제 핏·색상은 아래 실측 사이즈와 실물 사진을 확인해 주세요.` |
| 자사몰 착용컷 이미지 위 | `가상 인물` 배지 (모서리 고정) |
| 대사·자막 바꾸기 | ✗ "제가 일주일 입어봤는데 보풀 하나 없어요" → ○ "울 30% 혼방이라 보풀이 덜 생기는 소재예요(혼용률 기준)" |

### 5-3. 운영 권고
- 업로드 담당자는 §0 체크리스트를 **게시물마다** 채우고 스크린샷(토글 켠 화면)을 남긴다. 공정위 점검이나 플랫폼 이의제기 때 증빙이 된다.
- 자사몰에 AI 가상 피팅·AI 코디 추천·강유나 챗봇을 붙이는 기획이 생기면 그때 **AI 기본법 제31조① 사전고지**를 설계에 넣고 법률 검토를 받는다.
- 이 문서는 분기마다 다시 확인한다. 플랫폼 정책이 자주 바뀐다(예: Instagram 2026-08-31, YouTube 2026-05-27, TikTok 가이드 2026-09-24 판).

## 6. 확인 못 한 항목 (확인 불가)
1. Instagram 고객센터 'AI 레이블 지정' 도움말 본문(로딩 실패). 공개 의무 문구는 Meta 커뮤니티 규정 원문으로 대체 확인함.
2. Instagram 'AI로 생성한 프로필' 정책의 적용 지역(미국 한정 여부)과 한국 시행 여부.
3. Meta 브랜디드 콘텐츠 정책 원문(로딩 실패), 그리고 가상 인물 계정에 대한 별도 규정.
4. Meta 일반(비정치) 광고에서 제3자 AI 도구 사용 시 광고주 공개 의무 유무.
5. TikTok 앱 안의 AIGC 토글 정확한 메뉴 경로(고객센터 원문 로딩 실패. '더 보기 옵션'은 기사 근거).

7. YouTube '유료 프로모션 포함' 체크가 **자사 채널의 자사 상품 홍보**에도 필요한지(이번 조사 범위에서 원문 확인 안 함).

9. 공정위의 가상인물 표시 관련 실제 점검·제재 사례, '순수 모델컷'의 추천·보증 해당 여부에 대한 공식 해석.
