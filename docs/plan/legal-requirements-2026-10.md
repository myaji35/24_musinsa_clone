# 자사몰 판매 법적 요건 정리 (ISS-071, 2026-10-18)

> 법률 자문이 아니라 공개 법령·해설을 정리한 것이다. 실제 판매 개시 전 국가법령정보센터 원문(또는 전문가)으로 최종 확인할 것.
> 확인 수준 표기: **[원문]** 법률 조문 본문에서 확인 / **[2차]** 해설·블로그·결정문 요약으로만 확인(원문 대조 필요)

기준 법령: 「전자상거래 등에서의 소비자보호에 관한 법률」(이하 전자상거래법) 2026-01-20 일부개정(법률 제21312호, 2026-07-21 시행) — 위키문헌 전문 기준.

## 1. 통신판매업 신고 (전자상거래법 제12조)

| 항목 | 내용 | 확인 |
|---|---|---|
| 의무 | 통신판매업자는 공정위·지자체(시·군·구)에 신고해야 한다. 거래 횟수·규모가 공정위 고시 기준 이하면 예외 | [원문] |
| 신고 사항 | 상호(법인은 대표자 성명 포함), 주소, 전화번호, 전자우편주소, 인터넷 도메인, 호스트서버 소재지 등. 변경·휴업·폐업도 신고 | [원문] |
| 면제 기준 | 직전 연도 거래 50회 미만 또는 간이과세자 (공정위 고시) | [2차] |
| 미신고 제재 | 벌금 대상 | [2차] |

**JIEUN 판단:** 첫 매출은 50회 미만이어도 PG 심사(ISS-060)에 통신판매업 신고번호가 사실상 필요하다. 계좌이체 선개시를 하더라도 **판매 개시 전 신고를 권장**. 신고에는 사업자등록번호·구매안전서비스 이용확인증(PG 또는 에스크로)이 필요할 수 있음[2차] — 계좌이체만으로 신고할 때 에스크로 확인증 요건은 원문 확인 필요.

## 2. 몰 화면에 반드시 표시할 것

### 2-1. 사이버몰 하단 표시 (제10조) [원문]
1. 상호와 대표자 성명
2. 영업소 주소(소비자 불만 처리 장소 포함)
3. 전화번호·전자우편주소
4. 사업자등록번호
5. 이용약관
6. 그 밖에 대통령령 사항 — 통신판매업 신고번호, 호스팅 서비스 제공자 등 [2차]

### 2-2. 주문 전·주문 후 고지 (제13조·제14조) [원문]
- 광고(상품 화면)에 상호·대표자·주소·전화·전자우편·**신고번호와 신고기관** 포함
- 계약 전 거래조건 고지: 가격, 지급 방법·시기, 공급 방법·시기, **청약철회 조건·방법**, 환불 조건, 약관 등
- 계약 체결 후 재화 공급까지 계약내용 서면(주문 확인 메일/화면) 교부
- 주문 접수 사실·판매 가능 여부를 신속히 알리고, 주문 전 내용 확인·정정·취소 절차 제공 (제14조)
- 미성년자 계약 시 법정대리인 동의 없으면 취소 가능하다는 고지

**ISS-059 주문서 대조:** 주문 확인 화면·주문 조회는 있음. **청약철회 조건, 환불 조건, 사업자 정보, 미성년자 취소 고지가 주문서에 없음** → 몰 하단 고지 카드에서 함께 보강.

## 3. 청약철회·반품·환불 (제17조·제18조) [원문]

| 항목 | 규칙 |
|---|---|
| 기본 기간 | 계약내용 서면 받은 날부터 **7일** (공급이 더 늦으면 공급받은 날부터 7일) |
| 철회 제한 | 소비자 책임으로 멸실·훼손, 사용으로 가치가 현저히 감소 등. 단 내용 확인을 위한 포장 훼손은 제외. 제한 사유는 포장 등에 명확히 표시해야 제한이 인정됨 |
| 표시·계약과 다른 경우 | 공급받은 날부터 **3개월**, 안 날부터 **30일** 이내 철회 가능 |
| 환급 | 반환받은 날부터 **3영업일 이내** 환급, 지연 시 지연배상금. 카드 결제는 결제업자에 취소 요청 |
| 반품 비용 | 단순 변심은 **소비자 부담**, 사업자는 위약금·손해배상 청구 불가. 표시·계약과 다른 경우는 **사업자 부담** |
| 증명 책임 | 철회 제한 사유·공급 시기 다툼은 사업자가 증명 |

**의류 특이점:** "흰색 옷 반품 불가", "세일 상품 반품 불가" 같은 일괄 공지는 효력이 없다[2차]. 착용 흔적·택 제거 등 "가치 현저 감소"를 근거로만 제한 가능 → 택(tag) 부착 안내 + 수령 후 7일 철회 안내를 상품상세와 주문서에 함께 둔다.

## 4. 거래기록 보존 (제6조, 시행령 제6조)

| 기록 | 보존 기간 | 확인 |
|---|---|---|
| 표시·광고 기록 | 6개월 | [2차] |
| 계약·청약철회 기록 | 5년 | [2차] |
| 대금결제·재화 공급 기록 | 5년 | [2차] |
| 소비자 불만·분쟁 처리 기록 | 3년 | [2차] |

- 법 제6조 2026 개정: 보존 대상 거래기록과 **거래 주체를 식별할 수 있는 개인정보**는 소비자가 이용 동의를 철회해도 보존할 수 있다 [원문]
- 공정위 결정문에서 사이버몰 주문의 **주문자 정보·대금결제액·배송지** 미보존을 위법으로 다룬 사례가 있다 [2차]

### ⚠️ ISS-058 결정(C안)과의 충돌
ISS-058 C안: "동의하지 않았거나 비회원이면 배송 완료 후 90일 보관 뒤 파기". ISS-059 브랜치(`ShippingAddressPurgeJob`)는 이를 그대로 구현해 **배송지 레코드 자체를 90일 후 삭제**한다.
그러나 배송지는 "재화 공급 기록"의 일부로 **5년 보존 대상일 가능성이 높다**. 그대로 배포하면 거래기록 보존 의무 위반 소지가 있다.

정리안(추천): 두 용도를 분리한다.
- **주문 기록용 배송지 스냅샷**(주문 시점의 수령인·주소·연락처): 주문과 함께 5년 보관, 관리자 화면에서 열람 제한(분리 보관), 5년 경과 후 파기
- **재사용용 저장 배송지**(다음 주문 자동 채움): 동의한 경우만 보관, 비동의·비회원은 저장하지 않거나 90일 후 파기 — "주소는 지우고 취향은 잇다"는 이 범위에서 유지
- 개인정보처리방침·주문서 동의 문구를 "배송 목적 + 전자상거래법상 거래기록 5년 보존"으로 수정

→ 대표님 결정 카드로 분리(개인정보 처리 방식 변경). ISS-059 배포 전 확인에 함께 표시.

## 5. 약관·개인정보처리방침

| 문서 | 요건 | 확인 |
|---|---|---|
| 이용약관 | 몰 하단 표시 의무(제10조). 공정위 「전자상거래 표준약관」을 기반으로 작성하는 것이 일반적 | [원문]/[2차] |
| 개인정보처리방침 | 개인정보보호법 제30조: 처리 목적, 처리·보유 기간, 제3자 제공, 파기 절차·방법, 처리 위탁(택배사·PG), 정보주체 권리 행사 방법, 개인정보 보호책임자 등. 개인정보위 작성지침(2025 개정)·평가제 대상 | [2차] |
| 처리 위탁 고지 | 택배사·PG·호스팅(서버) 위탁 사실 기재 | [2차] |

## 6. 몰 하단 고지에 필요한 실제 값 (대표님 입력 필요)

상호 / 대표자 성명 / 사업장 주소 / 고객센터 전화·이메일 / 사업자등록번호 / 통신판매업 신고번호(신고기관) / 개인정보 보호책임자 / 호스팅 제공자.
→ 값이 없으면 하단 고지를 빈칸이나 가짜 값으로 배포하지 않는다(허위 표시가 더 위험). 별도 카드에서 값 수령 후 구현.

## 7. 후속 카드
1. **배송지 보관 방식 재결정** (DECISION, 대표님) — 4절 충돌 해소. ISS-059 배포 전 필요
