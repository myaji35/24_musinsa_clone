# 웹·패드·모바일·폰 화면 점검과 보완 (2026-11-17, ISS-214)

- **지시:** 대표님 2026-11-17 "웹, 패드, 모바일, 폰 사용자환경 디자인 점검 보완하자"
- **원칙:** 지난 리디자인이 "과하고 엉뚱하다"는 지적을 받았다. 그래서 이번에는 **새 스타일을 입히지 않고, 쓰기 불편한 결함만 고친다.** 색·글꼴·배치 콘셉트는 그대로 둔다.
- **측정:** `tmp/e2e/responsive.mjs` (사본 `docs/user-test/2026-11-17-responsive/`)
  - 기기 5종: web 1440 · pad 가로 1024 · pad 세로 820 · mobile 430 · phone 360
  - 페이지 18개: 손님 9, 관리자·회원 9
  - 기기와 페이지를 곱하면 총 90개 화면이다.

## 2. 보완 단계

- **R1 헤더·푸터·카테고리 칩 터치 영역**
  - 보이는 모양은 그대로 두고, 터치 기기와 좁은 화면에서 누르는 영역만 44px 이상으로 넓힌다.
  - `min-h`/`min-w`·padding·음수 margin을 쓴다.
- **R2 관리 표**
  - 거래처·발주·주문 관리 표는 `lg` 미만에서 카드 목록으로 보여 준다. `/admin/users`와 같은 방식이다.
  - 작업 버튼은 항상 보이게 한다.
- **R3 대시보드 차트와 모바일 관리 메뉴**
  - 차트는 폭에 맞추거나 '옆으로 밀기' 안내를 단다.
  - 빈 링크 원인을 수정한다.
- **R4 폼 터치 영역**
  - 체크박스·라디오·작은 링크의 누르는 영역을 넓힌다(주문서·가입·로그인·상품 등록).
- **R5 홈 인트로 최소 글씨 12px**
- **R6 재측정과 보고**
  - 90개 화면을 다시 측정해 전후 숫자를 비교한다.
  - 결과를 보기 창에 띄운다.
