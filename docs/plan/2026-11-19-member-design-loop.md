## 원칙 (11-10 럭셔리 리디자인 반성 반영)
- 한 회차 = 개선 하나. 회원이 실제로 막히거나 헷갈리는 지점에서 출발한다(캡처를 회원 눈으로 보고 고른다).
- 스타일 전면 개편 금지. 기존 토큰(색·글자·여백)과 컴포넌트 안에서 고친다. 인트로 연출 같은 장식 추가 금지.
- 관리자·운영자 화면은 범위 밖. 회원(로그인한 일반 회원)과 가입 전 손님이 보는 화면만.
- 브랜치 `design/member-loop`(feat/auth-roles 위, wt-auth). main 병합·배포 안 함.
- 회차마다: 캡처(전) → 개선안 1건 선정 → Codex 위임 → diff 검수 → 관련 테스트·rubocop → 캡처(후) → 커밋 → 이 기록 갱신.
- 5회차마다 전체 테스트·brakeman.
- 측정: 캡처 스크립트 scratchpad `loop/cap.mjs`(폰 390·웹 1440, 회원 e2e-member@jieun.test), 회차 결과 `loop/rNN/`.
