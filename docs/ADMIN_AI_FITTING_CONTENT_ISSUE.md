# HR-16 · 고객군 분석 기반 AI 피팅 이미지·5초 영상 제작

작성일: 2026-09-15 · 유형: 기능 기획 / 상위 이슈 · 우선순위: P1
상태: 기획 초안 / 구현·이미지 및 영상 생성 미착수
연계: [HR-15 엑셀 임포트](ADMIN_PRODUCT_IMPORT_ISSUE.md), [전체 이슈 목록](HOMEPAGE_RENEWAL_ISSUES.md)

## 1. 요청과 결과물

엑셀로 받아들인 상품 대표 이미지의 배경을 제거하고 보정한 뒤, 구매고객의 연령대·성별을 분석하여 해당 고객군에 맞는 실사형 가상 아바타를 만든다. 아바타가 상품을 착용한 여러 피팅 이미지와 5초 영상을 제작하고, 운영자가 검수한 결과를 상품에 게시한다.

여기서 실사형 아바타는 실존 구매고객을 복제한 모델이 아니라 사진처럼 보이는 가상의 성인 패션 모델을 뜻한다. 고객 분석은 집계 통계로 타깃을 선택하는 용도다. 피팅 결과는 스타일 연출 이미지이며 실제 착용 실험이나 개인별 사이즈 적합도 측정 결과로 취급하지 않는다.

초기 결과물 제안: 상품·색상 기준 원본 1개, 누끼 PNG 1개, 보정 상품 이미지 1개, 대표 고객군용 아바타 1종, 피팅 이미지 3종, 5초 영상 1개. 최대 2개 고객군을 선택할 수 있으나 기본은 1개이며 추가 고객군은 별도 생성 수와 비용으로 계산한다.

## 2. 전체 처리 흐름

엑셀 임포트 완료 → 원본 적합성 확인 → 누끼 제거 → 보정·상품 동일성 검수 → 구매고객군 분석 → 타깃 선택 → 아바타 후보 생성·선택 → 피팅 이미지 생성·검수 → 승인 이미지 기반 5초 영상 → 최종 검수 → 상품에 게시

자동화는 각 단계의 초안을 생성하는 데 적용한다. 비용이 발생하는 묶음 작업은 운영자가 범위와 예상 비용을 확인하고 시작하며, 공개는 별도의 게시 동작으로 실행한다. 원본 임포트만으로 생성 비용이 발생하거나 기존 대표 이미지가 교체되지 않는다.

## 5. 원본·누끼·보정 정책

- 임포트 원본은 변경하지 않고 해시·출처·상품·색상·파일 버전을 보존한다. 누끼·보정·피팅 결과는 별도 파생 자산이다.
- 입력을 상품 단독 컷 / 행거·마네킹 컷 / 사람이 착용한 컷 / 사용 불가로 분류하고 운영자가 확인한다. 착용 사진의 배경 제거만으로 독립된 의류를 확보했다고 취급하지 않는다.
- 대상 의류가 가려졌거나 여러 상품 중 대상이 불명확하면 상품 지정 또는 추가 이미지를 요구하는 `자료 보완 필요` 상태로 둔다. 흐림·저해상도·잘린 소매·보이지 않는 주요 디테일도 확인한다.
- 누끼 결과는 배경 투명 PNG로 보관한다. 반투명 소재·레이스·프린지·머리카락과 겹친 옷 경계의 누락은 수동 마스크 수정 또는 재처리할 수 있게 한다.
- 보정은 노출·화이트밸런스·불필요한 배경 잔여·노이즈·구도 정리를 중심으로 한다. 실제 색상·로고·패턴·원단 결·제품 형태를 바꾸는 결과는 반려한다.
- 색상은 입력 사진 기준으로 비교하며 실제 상품과의 일치는 운영자가 확인한다. 색상 기준표나 실물 정보가 없으면 “정확한 실물 색 복원”으로 설명하지 않는다.
- 원본에 없는 뒷면, 숨은 장식, 소재 구조를 복원했다고 표시하지 않는다. 뒷모습·회전 피팅을 원하면 해당 면의 추가 참고 이미지를 받는다.

## 6. 구매고객 연령대·성별 분석

### 데이터와 집계 기준

- 기본 기간은 최근 90일 제안이며 30/90/180일 선택을 제공한다. 현재 데이터만 사용할 때는 주문 생성일 기준, 현재 상태가 paid/shipped/delivered인 주문을 대상으로 한다. cancelled/pending는 제외한다.
- 반품·환불 데이터가 없으면 `반품·환불 미반영`을 표시한다. 이를 순구매 고객 분석으로 명명하지 않는다. 결제일·환불 이력이 연결되면 별도 버전의 집계 기준으로 확장한다.
- 주 지표는 상품별 고유 고객 식별자 수다. 같은 고객의 반복 구매가 고객군 비중을 과도하게 높이지 않도록 중복 제거한다. 주문 건수·구매 수량·금액은 보조 지표로 분리한다.
- 기본 연령대: 20세 미만 / 20대 / 30대 / 40대 / 50대 / 60세 이상 / 미상. birth_year만 있을 때는 분석 기준연도와의 차이로 구한 추정 연령대임을 표시한다. 잘못된·결측 연도는 미상 처리한다.
- 성별은 구매자가 직접 제공했거나 사용 목적이 확인된 구매 데이터의 값을 사용한다. 미상·미응답을 유지하고 사진·이름·구매 상품·Product.gender로 추정해 채우지 않는다. 연령대와 성별 모두 알려진 집계와 전체 집계의 분모를 각각 표시한다.
- 외부 자료가 필요하면 개인 식별정보 대신 기간·상품코드·연령대·성별·고객 수·주문 수를 가진 집계 파일 연계를 우선한다. 외부 집계와 내부 주문을 중복 합산하지 않으며 중복 제거가 불가능한 자료는 출처별로 표시한다.
- 전화번호 뒤 4자리와 출생연도는 외부 결합 키로 쓰지 않는다. 기존 UUID 충돌·중복 가능성을 확인하고 해결 전에는 `식별자 기준 고객 수`로 표현한다.

### 타깃 추천과 데이터 부족

- 상품별 유효 고객 식별자 30명 이상일 때 자동 고객군 추천을 제공하는 초기 기준을 제안한다. 10명 미만인 교차집계 그룹은 상세 수치를 숨기고 작은 그룹 수를 역산할 수 있는 총계·비중 표시도 제한한다. 기준 수치는 운영 데이터 확인 후 확정한다.
- 성별·연령대 유효값 비율이 각각 70% 미만이면 해당 축의 자동 추천을 보류한다. 알려진 값만으로 전체 고객을 대표한다고 표시하지 않는다.
- 표본·유효값이 충분한 축에서만 고객 수 상위 고객군 최대 2개를 제안한다. 동률이면 운영자가 선택한다. 기준 미충족 시 상품 → 카테고리 집계 제안 → 운영자 수동 선택 순으로 진행하며 어떤 근거를 사용했는지 표시한다.
- 신상품·구매 이력 없음은 `분석 데이터 없음`으로 표시한다. 수동으로 타깃 연령대·모델 표현을 선택해 제작할 수 있으나 분석 기반 추천이라고 기록하지 않는다.
- 성인 모델 제작을 1차 범위로 제안한다. 20세 미만 집계가 주요 고객군인 상품은 성인 모델로 자동 치환하지 않고 타깃 기획을 별도 검토한다.
- 고객군 분석은 연출 대상의 참고자료다. 구매자가 실제 착용자라고 가정하거나, 성별·연령대로 체형·피부색·외모·성격을 자동 결정하지 않는다.

분석 결과에 기간, 집계 규칙 버전, 표본 수, 미상 비율, 출처, 선정 사유, 운영자 수정 이력을 저장한다. 이 스냅샷을 해당 생성 작업과 연결한다.

## 7. 실사형 아바타 모델

- 입력 설정: 선택한 성인 연령대, 성별 표현, 운영자가 선택한 체형·키 범위·헤어·포즈·촬영 분위기. 고객에게 확인되지 않은 신체 특징을 분석 결과로 생성하지 않는다.
- 첫 모델 후보는 2종을 제안하고 운영자가 1종을 선택한다. 검수 포인트는 자연스러운 얼굴·손·신체 비율, 타깃 적합성, 의상 가림 정도다.
- 승인 모델에 avatar_id·버전과 재사용할 참조 이미지를 부여한다. 같은 상품의 피팅 이미지·영상은 같은 모델 버전을 사용한다. 다른 버전을 사용하면 별도 세트로 구분한다.
- 실존 고객 사진이나 유명인 얼굴 복제는 기본 입력에 포함하지 않는다. 외부 생성 서비스에는 고객별 구매 내역·고객 식별자 대신 선택한 고객군 조건과 필요한 상품·모델 참조만 전달한다.
- 아바타 재사용을 기본으로 하되 모델 버전 변경 시 기존 공개 자산을 자동으로 다시 만들거나 교체하지 않는다.

## 8. 여러 피팅 이미지

초기 세트는 3종으로 제안한다: 정면 전신 / 확인 가능한 범위의 약한 측면 포즈 / 상반신·상품 디테일 중심 컷. 세 컷 모두 승인 모델과 같은 상품·색상 버전을 사용한다.

필수 입력은 검수된 상품 누끼·보정 이미지, 승인 아바타, 상품 설명·소재·실측 정보 중 실제 제공된 값이다. 실측 정보가 없으면 신체에 대한 정확한 기장·핏을 보증하지 않는다. 원본 한 장으로 지원하기 어려운 각도는 정면 포즈·구도 변형으로 대체하고 변경 사유를 기록한다.

출력은 4:5 세로, 최종 1080×1350px 이상을 초기 목표로 한다. 원본 해상도와 생성 품질에 따라 통과 여부를 검수하며 확대만으로 세부정보가 복원됐다고 판단하지 않는다.

상품 동일성 검수: 색상, 로고·문자, 무늬 위치·반복, 여밈, 포켓·봉제선, 소매·기장, 소재 표현. 모델 검수: 얼굴·손·신체 비율, 같은 세트 내 모델 일치, 포즈의 자연스러움. 오탈자 로고, 사라진 단추, 다른 원단처럼 보이는 결과는 재생성 또는 반려한다.

원본·누끼/보정·AI 피팅을 자산 유형으로 구분한다. AI 피팅은 실제 촬영한 상품 사진과 혼동되지 않도록 공개 영역에 `AI 모델 착용 연출 이미지` 안내를 제공한다. 실제 상품 확인용 원본 또는 검수된 상품 컷도 함께 제공한다.

## 9. 5초 피팅 영상

- 입력: 승인한 피팅 이미지 1개 또는 같은 모델·상품 버전의 승인 참조 세트. 반려·검수 전 이미지로 영상 생성하지 않는다.
- 기본 연출: 0~1초 안정된 정면 → 1~4초 작은 포즈 변화 또는 천천히 가까워지는 카메라 → 4~5초 안정된 상품 확인 컷. 큰 회전·원본에 없는 뒷면·과한 옷 변형은 피한다.
- 결과 규격 제안: 무음 MP4, 4:5, 1080×1350, 30fps, 정확히 150프레임으로 5초. 생성 서비스 출력 길이가 다르면 후처리로 규격을 맞추고 품질을 다시 확인한다. 9:16 광고용·배경음악·대사·입 모양 연출은 후속 범위다.
- 대표 포스터는 승인 프레임에서 선택한다. 상품 상세에서 직접 재생 가능하게 하고 자동재생 여부는 별도 화면 정책으로 정한다.
- 검수: 처음·중간·끝 프레임과 전 구간에서 얼굴·의류·로고·색상 일관성, 손·다리 오류, 깜빡임, 원단 늘어짐, 프레임 경계·길이·재생 호환 확인. 자동 점검은 검수 보조이며 관리자 확인을 대체하지 않는다.
- 공개 화면에 `AI 생성 피팅 영상`을 표시한다. 임포트 원본과 피팅 이미지의 게시 상태는 영상 재생성·실패와 독립적으로 유지한다.

## 10. 작업·버전·비용·게시

| 관리 대상 | 저장할 핵심 정보 |
|---|---|
| 상품 원본·파생 자산 | product_id, 색상/옵션 참조, 원본 해시·버전, 자산 유형, 부모 자산, 파일, 규격, 상태 |
| 고객 분석 스냅샷 | 기간, 출처, 집계 규칙, 표본·결측률, 고객군 추천·수동 선택 근거 |
| 아바타 | 모델 ID·버전, 승인 참조, 설정, 승인자·시각 |
| 생성 작업 | 단계, 입력 자산 버전, 제공 서비스/모델 버전, 설정·프롬프트 기록, 외부 작업 ID, 상태, 시도 수, 비용 |
| 검수·게시 | 승인/반려 사유, 검수자, 게시 대상·순서, 게시 버전, 이전 게시 버전 |

단계 상태: 대기 → 처리 중 → 검수 대기 → 승인 / 반려 / 실패. 자산 게시 상태는 미게시 / 게시 / 게시 철회로 별도 관리한다. 반려는 사용자의 품질 판단, 실패는 처리 오류다.

작업 재시도는 실패한 단계부터 수행한다. 재전달·중복 클릭·콜백 중복 시 같은 외부 작업이 여러 번 과금되지 않도록 입력 버전과 실행 키를 관리한다. 타임아웃은 즉시 새 생성으로 재시도하지 않고 외부 작업 ID의 완료·과금 상태를 먼저 확인한다. 자동 재시도는 초기 1회 제안이며 추가 재생성은 관리자 실행으로 한다.

상품별·묶음별·일별 비용 상한과 동시 실행 수를 설정한다. 실행 전 상품 수 × 고객군 수 × 이미지/영상 수와 예상 비용 범위를 보여준다. 가격은 서비스 후보와 실측이 없으므로 이 문서에서 산정하지 않는다. 예상 비용을 알 수 없으면 대량 실행을 열지 않고 제한된 샘플 작업부터 검증한다.

대기 작업 취소와 처리 중 취소 요청을 구분한다. 외부 서비스가 이미 작업 중이면 취소가 즉시 중단·환불을 의미하지 않는다는 상태를 보여준다. 비용·재시도 결과는 실행 이력에 기록한다.

원본 상품 이미지·색상·상세가 변경되면 그 버전에서 생성된 결과를 `재검수 필요`로 표시하고 신규 게시를 막는다. 이미 게시된 관련 생성 자산은 숨기고 검수된 상품 원본으로 대체하는 것을 기본 정책으로 제안한다. 독립 승인된 다른 색상·상품 자산까지 숨기지 않도록 의존 관계를 추적한다.

게시할 때 대표 이미지·상세 갤러리·영상 위치를 선택하고 순서를 미리 본다. 기본 대표 이미지는 검수된 상품 컷이며 AI 피팅으로의 교체는 명시적으로 선택한다. 게시 철회는 이전 승인 버전으로 되돌릴 수 있게 하고, 공개 캐시도 갱신한다. 초안 상품은 자산을 승인해도 공개되지 않는다.

원본·실패·반려 자산은 비공개로 보관하고 관리자 권한을 적용한다. 적용 중인 자산과 이전 게시 복원용 자산을 임시 파일 정리에서 제외한다. 미게시 후보·실패 파일 보관 기간은 30일, 생성·검수 이력은 180일을 초안으로 제안하며 실제 운영 정책과 맞춘다.

## 12. 인수 기준

- [ ] 엑셀 임포트 상품을 선택해 누끼·보정·분석·아바타·피팅·영상 작업을 이어 실행할 수 있다.
- [ ] 임포트만으로 유료 생성·공개 변경이 발생하지 않고 원본 파일이 보존된다.
- [ ] 단독 컷·착용 컷·잘린 이미지·반투명 소재를 구분하고 상품 추출이 불명확하면 보완 상태로 처리한다.
- [ ] 색상·문양·로고·주요 디테일이 다른 누끼·보정·피팅 결과는 반려할 수 있다.
- [ ] 연령·성별 결측, 전체 데이터 없음, 고객 29/30명 경계, 작은 집계 그룹, cancelled/pending 주문에서 규칙대로 집계·추천한다.
- [ ] 반품 데이터 없는 집계와 birth_year 기반 추정 연령대의 한계가 표시되고 Product.gender가 고객 성별에 섞이지 않는다.
- [ ] 신상품은 근거를 표시한 수동 타깃 선택으로 제작할 수 있다. 고객 정보를 생성 서비스에 원시 형태로 보내지 않는다.
- [ ] 아바타 후보 선택 후 이미지 3종과 영상에서 같은 모델·상품·색상 버전을 유지한다. 일관성 실패 시 게시할 수 없다.
- [ ] 원본 한 장에서 보이지 않는 뒷면이 필요한 요청은 추가 참조를 요구하거나 허용된 정면 변형으로 조정한다.
- [ ] 영상은 5초·150프레임·제안한 해상도·무음 규격을 충족하고 전 구간 모델·의류·로고 왜곡을 검수한다.
- [ ] 중복 실행·콜백·타임아웃·재시도·비용 상한 초과 시 중복 과금 방지와 작업 이력이 검증된다.
- [ ] 승인 전 자산은 공개되지 않고, 게시 결과에 AI 연출 안내와 실제 상품 확인용 이미지가 함께 제공된다.
- [ ] 원본 교체 시 관련 생성물만 재검수 대상으로 바뀌고, 이전 원본에 기반한 결과를 새 상품 이미지처럼 노출하지 않는다.
- [ ] 영상 실패가 승인 이미지나 임포트 원본을 손상시키지 않는다. 게시 철회로 이전 승인 버전과 캐시를 복원할 수 있다.
- [ ] 실제 샘플로 최초 검수 통과율·재생성 횟수·상품당 비용·단계별 시간을 기록하고 대량 제작 가능 여부를 판단한다.

## 13. 선행 확인과 기획상 제한

미확정 입력: 공급 엑셀의 이미지 형태·촬영 각도·해상도, 구매고객 성별 데이터 출처, 출생연도 입력률·고객 식별 정확도, 제작 상품 카테고리, 통상 생성 수량·예산.

가방·신발·액세서리는 의류와 다른 착용 합성이 필요하므로 샘플 검증 후 지원 범위를 구분한다. 신체 치수 기반 정밀 사이즈 추천, 실제 고객 얼굴을 이용한 개인 피팅, 미성년 아바타, 전면·후면 정보 없는 360도 회전은 초기 기본 범위에 포함하지 않는다.

본 이슈의 완료는 기획과 작업 명세 작성까지다. 실제 고객 데이터 분석, 외부 서비스 호출, 누끼·이미지·영상 제작, 서비스 선정·결제, 코드 변경·배포는 수행하지 않았다.
