대표님 지시(2026-11-19): "운영자 관점에서 디자인 개선 — 20회 운영, 회차별로 개선안을 도출하고 개선한 뒤 다음 회차에서 다시 개선안을 도출."

## 진행 방식
1. 개발 서버(3053)에 운영자 계정(`ego-op@jieum.test`)으로 로그인해 운영 메뉴 14개 화면을 데스크톱(1366)·휴대폰(390)으로 찍는다(점검 스크립트: 세션 scratchpad의 `round-shot.mjs`).
2. 운영자가 매일 하는 일(발주 확인·입고·주문 처리·재고 확인) 기준으로 가장 불편한 점 1~3개를 고른다.
3. Codex가 고치고, 나는 diff 검수 → 전체 테스트 → 다시 찍어 화면으로 확인한 뒤 커밋한다.
4. 운영 배포는 회차와 별개로 대표님 승인 후 한꺼번에 한다.
