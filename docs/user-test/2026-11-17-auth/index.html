  • 역할 3개(관리자·운영자·일반 회원) + 비로그인 손님. 관리자 판정을 역할 기준으로 바꿔 '소속 계정 없으면 관리자'로 보던 위험을 제거했습니다.
  • 회원가입 /join(항상 일반 회원, 역할 끼워 넣기 차단) · 로그인/가입 3분 10회 제한 · 내 정보 /my · 내 주문 /my/orders(ISS-212 회원 주문 연결).
  • 역할별 메뉴(운영자 8개, 관리자 13개) · 관리자 사용자·역할 관리 /admin/users(본인 변경·마지막 관리자 강등 차단).
  • 검증: 요청 테스트 806 · 시스템 테스트 15 · 실패 0, rubocop 0, brakeman 0. 실제 서버로 4개 역할 흐름 끝까지 통과, 375px 가로 넘침 0.
